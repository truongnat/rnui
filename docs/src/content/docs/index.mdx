<div class="section">
  <h2>Own your components.</h2>
  <p>
    RNUI is not a component library you import — it's a registry you copy from.
    Every component lands in <code>components/ui/</code> inside your project.
    Your code, your tokens, your changes. No upstream package to fight.
  </p>

  <Card title="Copy-paste, owned" icon="document">

<div class="section">
  <h2>From zero to component in two commands.</h2>

```bash
npx github:truongnat/rnui#cli init        # engine deps + metro/babel + theme
npx github:truongnat/rnui#cli add button  # → components/ui/button.tsx
```

  <p>
    No publish, no install — the CLI runs straight from git. Under the hood it
    wraps <code>shadcn add</code>, so the registry is fully compatible with the
    shadcn toolchain.
  </p>
</div>
