Searchable command palette modal.

## Install

```bash
npx @rnui/cli add command
```

or directly via the shadcn CLI:

```bash
npx shadcn add https://<registry-base>/r/nativewind/command.json   # or /uniwind/
```

**npm dependencies installed automatically:** `lucide-react-native`

## Usage

```tsx
<Command
  open={open}
  onOpenChange={setOpen}
  items={[
    { label: 'Profile', value: 'profile' },
    { label: 'Settings', value: 'settings' },
  ]}
  onSelect={(item) => console.log(item.value)}
/>
```
