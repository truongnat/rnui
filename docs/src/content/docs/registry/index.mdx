These components are installed as **source code you own** via the registry —
the same model as shadcn/ui. They work with both styling engines:
**nativewind** and **uniwind**.

## Quick start

```bash
npx @rnui/cli init            # one-time setup (engine deps, metro/babel, theme)
npx @rnui/cli add button      # install a component
npx @rnui/cli list            # show all items
```

## Themes

Brand themes swap the semantic CSS variables in `global.css`:

```bash
npx @rnui/cli add theme-matcha
```

- **Butter** (`theme-butter`) — Golden buttery surfaces with a blue accent
- **Chocolate** (`theme-chocolate`) — Warm brown tones and cozy beige
- **Gothic** (`theme-gothic`) — Atmospheric deep blue-gray, dark-first
- **Matcha** (`theme-matcha`) — Earthy green, calm and organic
- **Neutral** (`theme-neutral`) — Muted, minimal slate with a restrained blue accent
- **Stone** (`theme-stone`) — Warm stone and slate tones
- **Y2K** (`theme-y2k`) — Periwinkle body with holographic pink accents
