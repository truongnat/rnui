Pressable button with variant + size styles via tailwind-variants slots.

## Install

```bash
npx @rnui/cli add button
```

or directly via the shadcn CLI:

```bash
npx shadcn add https://<registry-base>/r/nativewind/button.json   # or /uniwind/
```

**npm dependencies installed automatically:** `tailwind-variants`

## Usage

```tsx
<Button onPress={() => {}}>Primary</Button>
<Button variant="secondary" size="sm">Secondary</Button>
<Button variant="outline">Outline</Button>
<Button variant="destructive">Delete</Button>
```
