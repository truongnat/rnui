Typography primitives with shadcn-style variants (h1-h4, p, lead, muted, blockquote, code).

## Install

```bash
npx @rnui/cli add text
```

or directly via the shadcn CLI:

```bash
npx shadcn add https://<registry-base>/r/nativewind/text.json   # or /uniwind/
```

**npm dependencies installed automatically:** `tailwind-variants`

## Usage

```tsx
<Text variant="h1">Title</Text>
<Text variant="p">Body text</Text>
<Text variant="muted">Muted text</Text>
```
