## Install

```bash
npx github:truongnat/rnui#cli add toast
```

or directly via the shadcn CLI:

```bash
npx shadcn add https://<registry-base>/r/nativewind/toast.json   # or /uniwind/
```


## Usage

```tsx
// Wrap your app once:
<ToastProvider>
  <App />
</ToastProvider>

// Then anywhere:
const { toast } = useToast();
toast({ title: 'Saved', description: 'It worked.' });
toast({ title: 'Failed', variant: 'destructive' });
```
