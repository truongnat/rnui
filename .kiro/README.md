# Kiro Configuration for RNUI Project

This directory contains Kiro IDE configuration: MCP servers and steering rules.

## Directory Structure

```
.kiro/
├── settings/
│   └── mcp.json                  # MCP server configuration
└── steering/
    ├── get-shit-done-workflow.md # Task management workflow
    └── safety-checklist.md       # Pre/post-edit checklist
```

## MCP Servers

### Get Shit Done (Task Management)

- **Purpose**: Task tracking and productivity management

## Workflows

Steering files with `inclusion: auto` load automatically and guide the agent's workflow (see `safety-checklist.md` for the pre/post-edit checklist).
